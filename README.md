# 15 灯拍击跑马灯（Arduino Nano + WS2812B）

一个桌面级随机点灯小游戏。拍一下开始乱闪，再拍一下停下，停下时**恰好亮 2 盏或 3 盏**。
配 16 个拨动开关，可以把任意一盏灯排除在游戏之外，该灯全程不亮。

## 最值得看的设计：观众无法从停止位置反推结果

如果「停下时亮哪几盏」由停止那一刻的灯位决定，玩几轮所有人都能算出规律——
看到灯走到第 7 颗再拍，就永远中同一组。

这个固件的做法是**先抽结果，再演动画**：

```
按下停止键
   ↓
立刻从「启用的灯」里抽好目标结果（真随机，与当前灯位无关）
   ↓
用 700ms 的减速动画把结果"演"出来
   ↓
锁 15 秒展示结果，期间不响应按键
```

跑马灯本身无规律（速度带随机抖动），观众看到的收束过程只是表演，**不携带任何关于结果的信息**。

对应代码：

```c
#define LOCK_MS      700     // 减速收束时长，500~900 效果最好
#define RESULT_MS    15000   // 结果保持时间
#define SPEED_MIN    25      // 乱闪最快间隔（ms）
#define SPEED_VAR    18      // 速度抖动幅度，越大越"无规律"
#define IDLE_LEVEL   6       // 待机微光亮度 0~255，设 0 则待机全灭
```

`LOCK_MS` 是这个项目唯一的魔法数字：太短看不出收束感，太长观众会怀疑程序在算。

## 硬件

| 项 | 型号 | 说明 |
|---|---|---|
| 主控 | Arduino Nano (ATmega328P) | 引脚刚好够用，不建议换更小的板 |
| 灯珠 | WS2812B × 15 | 串联，单数据线 |
| 输入 | 拍击按钮 × 1 + 拨动开关 × 16 | 开关用于排除某盏灯 |

引脚分配：

```c
#define LED_PIN    6    // 灯带数据
#define BTN_PIN    4    // 拍击按钮
#define MODE_PIN   5    // 模式切换
const uint8_t DIS_PINS[NUM_LEDS] = {2, 3, 7, 8, 9, 10, 11, 12, 13, A0, A1, A2, A3, A4, A5};
```

## 烧录

1. Arduino IDE 打开 `firmware/firmware-simple.ino`
2. 库管理器搜索安装 **Adafruit NeoPixel**
3. 开发板选 Arduino Nano，处理器选 **ATmega328P**
   （老款国产板若上传失败，改选 **ATmega328P (Old Bootloader)**）
4. 上传

## 可调项

- **难度**：改亮的灯数（2 盏 / 3 盏）与开关排除的灯数
- **节奏**：`SPEED_MIN` 调乱闪快慢，`LOCK_MS` 调收束手感
- **待机**：`IDLE_LEVEL` 给个微光，桌面更好看；设 0 则全灭
